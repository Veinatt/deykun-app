# Структура проекта Deykun Marketing

## Обзор

Проект представляет собой лендинговую страницу для маркетингового агентства, переписанную с HTML/CSS/JS на современный стек: **React + TypeScript + Vite**. Проект подготовлен для будущей интеграции с **Directus CMS** через API.

## Технологический стек

- **React 19** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик и dev-сервер
- **Redux Toolkit** - управление состоянием
- **React Router** - маршрутизация
- **Framer Motion** - анимации
- **Swiper** - слайдеры
- **SCSS Modules** - стилизация
- **React Hook Form + Yup** - формы и валидация

## Описание основных директорий

### `/src/components`

#### `layout/` - Компоненты макета

- **Header** - Шапка сайта с навигацией и бургер-меню

  - Управление состоянием меню через Redux (`uiSlice`)
  - Адаптивное меню для мобильных устройств
  - Интеграция с модальным окном заявки

- **Footer** - Подвал сайта
  - Контактная информация
  - Социальные сети
  - Копирайт

#### `sections/` - Секции главной страницы

Каждая секция - отдельный компонент, который получает данные через props (в будущем из Directus API):

- **HeroSection** - Главный экран с заголовком, описанием и CTA
- **PurposeSection** - Секция "Для чего это нужно?" с карточками
- **WhyUsSection** - Преимущества компании
- **ExcludedSection** - Ситуации, которые исключены
- **ServicesSection** - Тарифы с табами (Решения, Инструменты, Сопровождение)
- **PortfolioSection** - Кейсы с использованием Swiper
- **ReviewsSection** - Отзывы клиентов
- **FAQSection** - Часто задаваемые вопросы с аккордеонами
- **ContactSection** - Контактная форма и информация

#### `ui/` - Переиспользуемые UI компоненты

- **Button** - Универсальная кнопка с вариантами стилей
- **Modal** - Модальное окно для форм
- **Accordion** - Аккордеон для FAQ
- **Tabs** - Табы для переключения категорий тарифов
- **Swiper** - Обертка для библиотеки Swiper

#### `shared/` - Общие компоненты

- **RequestForm** - Форма заявки (используется в модалке и на странице)
- **ScrollToTop** - Компонент для прокрутки наверх

### `/src/pages` - Страницы приложения

- **HomePage** - Главная страница, собирает все секции
- **SuccessPage** - Страница успешной отправки формы
- **ErrorPage** - Страница ошибки при отправке формы

### `/src/store` - Redux хранилище

#### Slices:

1. **modalSlice** - Управление модальными окнами

   - `isOpen` - открыто ли модальное окно
   - `modalType` - тип модального окна ('request' | 'example')
   - `modalData` - данные для модального окна (источник, тип формы)

2. **formSlice** - Состояние форм

   - `isSubmitting` - идет ли отправка формы
   - `submitError` - ошибка при отправке
   - `submitSuccess` - успешная отправка

3. **uiSlice** - UI состояние
   - `isMenuOpen` - открыто ли меню
   - `isScrolled` - прокручена ли страница
   - `activeTab` - активная вкладка
   - `activeAccordion` - открытый аккордеон

### `/src/services` - Сервисы

- **api.ts** - API клиент для Directus

  - Все функции возвращают промисы с данными
  - Сейчас используются моковые данные
  - Готов к интеграции с Directus API

- **formService.ts** - Сервис отправки форм
  - `submitForm()` - отправка формы
  - `validatePhone()` - валидация телефона
  - `formatPhone()` - форматирование телефона

### `/src/types` - TypeScript типы

- **content.types.ts** - Типы для контента из Directus

  - Все типы соответствуют структуре коллекций Directus
  - Базовый тип `DirectusEntity` с общими полями
  - Типы для каждой секции: `HeroContent`, `PurposeSection`, `Rate`, `CaseStudy`, etc.

- **index.ts** - Центральный экспорт типов
  - Типы для Redux (`RootState`, `AppDispatch`)
  - Типы для форм (`IFormData`)
  - Типы для UI (`UIState`)

### `/src/hooks` - Кастомные хуки

- **useFormSubmit** - Хук для отправки форм с обработкой ошибок
- **useScrollPosition** - Хук для отслеживания позиции скролла
- **useToggle** - Хук для переключения boolean состояния

### `/src/utils` - Утилиты

- **constants.ts** - Константы приложения

  - `APP_CONFIG` - основная конфигурация
  - `NAVIGATION` - маршруты
  - `SOCIAL_LINKS` - ссылки на соцсети
  - `SERVICE_CATEGORIES` - категории услуг
  - `BREAKPOINTS` - брейкпоинты для адаптива

- **helpers.ts** - Вспомогательные функции
  - Утилиты для форматирования
  - Валидация
  - Обработка данных

### `/src/styles` - Глобальные стили

- **globals.scss** - Главный файл, импортирует все остальные
- **\_variables.scss** - SCSS переменные (цвета, шрифты, отступы, брейкпоинты)
- **\_mixins.scss** - SCSS миксины для переиспользования стилей
- **\_reset.scss** - Сброс стилей браузера
- **\_animations.scss** - Ключевые кадры анимаций

## Принципы организации

### 1. Модульность

- Каждый компонент в отдельной папке с собственными стилями (CSS Modules)
- Компоненты независимы и переиспользуемы

### 2. Типизация

- Все данные типизированы через TypeScript
- Типы для контента готовы к интеграции с Directus

### 3. Управление состоянием

- Redux для глобального состояния (модалки, формы, UI)
- Локальное состояние через `useState` для простых случаев

### 4. Динамический контент

- Все тексты, изображения, данные приходят через props
- Готовность к замене на данные из Directus API

### 5. Анимации

- Framer Motion для плавных анимаций появления элементов
- Анимации при скролле (Intersection Observer)

### 6. Адаптивность

- Mobile-first подход
- Брейкпоинты определены в переменных
- Бургер-меню для мобильных устройств

## Интеграция с Directus

### Текущее состояние

- Все типы данных соответствуют структуре Directus коллекций
- API сервис готов к подключению
- Моковые данные используются для разработки

### Будущая интеграция

1. Настроить переменную окружения `VITE_DIRECTUS_URL`
2. Раскомментировать реальные запросы в `services/api.ts`
3. Настроить аутентификацию Directus (если требуется)
4. Заменить моковые данные на реальные запросы

### Пример использования:

```typescript
// В компоненте
import { getHeroContent } from "@/services/api";

const HeroSection = () => {
  const [content, setContent] = useState<HeroContent | null>(null);

  useEffect(() => {
    getHeroContent().then(setContent);
  }, []);

  // Использование content...
};
```
